# Getting familiar with data migration and data transformation

In this project, I will be working on data migration and data transformation. 
I will follow coding samples provided in SQL Server 2017 Integration Services Cookbook. 


The main goal is: 
1. explore different components of SQL Server Integration Services (SSIS) and how to use them for data migration and transformation.
2. learn how to create and manage SSIS packages, and how to deploy and execute them.
3. learn the logging and error handling features of SSIS, and how to use them to troubleshoot and optimize data migration and transformation processes.


we will be working [migration run book](migration_run_book.md) as well.
